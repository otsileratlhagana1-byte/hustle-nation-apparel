## How to run in Pydroid 3

1. Install Pydroid 3.
2. Open Pydroid 3's Pip section and install Flask:
   pip install flask
3. Extract this ZIP.
4. Open `app.py` in Pydroid 3.
5. Press Run.
6. Open the address shown by Flask, normally:
   http://127.0.0.1:5000

If `127.0.0.1:5000` does not open, try:
   http://localhost:5000

## Important
The website uses the exact product prices visible in the supplied price-list image. The photos are used as visual mockups for the corresponding product groups. Before taking live payments, connect your preferred payment gateway and confirm stock, sizes, delivery fees and payment terms.
